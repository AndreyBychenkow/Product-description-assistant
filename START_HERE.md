# 🚀 Первый запуск — Windows PowerShell

**Полный проект, не обновление. Старые файлы не нужны.** Python 3.12+; если он уже установлен, повторно устанавливать его не надо. LLM на компьютер не скачивается.

## 1. Подготовь папку

Распакуй архив. Открой PowerShell **в папке с `run.py` и `requirements.txt`**.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если команда `python` не найдена, используй установленный Python Launcher: `py -3 -m venv .venv`.

Это обычные библиотеки приложения, не модель. Активация окружения и изменение ExecutionPolicy не требуются.

## 2. 🔑 Сохрани ключ без редактирования файлов

```powershell
.\.venv\Scripts\python.exe -m scripts.configure
```

При запросе **`Paste OpenRouter API key (hidden):`**:

1. Вставь полный секретный ключ OpenRouter, не его название `qwen_new`.
2. Нажми Enter. Символы не отображаются — это нормально.
3. Дождись сообщения «Готово».

Команда сама создаст `.env`, выберет проверенную NVIDIA-модель и режим новой генерации. Реальный ключ не включен в архив/Git. Если он уже сохранен, Enter позволяет оставить его.

## 3. ✅ Проверь API и запусти

```powershell
.\.venv\Scripts\python.exe -m scripts.check_connection
```

Ожидается **`"ok": true`**. Это один небольшой настоящий API-запрос. При ошибке см. таблицу ниже.

```powershell
.\.venv\Scripts\python.exe run.py --host 127.0.0.1
```

Оставь PowerShell открытым. В браузере открой:

**http://127.0.0.1:8010/**

## 4. 📝 Получи две карточки

1. Выбери **testo 830-T1** — заполнится JSON.
2. Нажми **«Сформировать карточку»** — это новый запрос к LLM.
3. Дождись результата. Проверь текст, характеристики и предупреждения.
4. **«JSON» → «Скачать JSON»** — сохрани результат.
5. **«Markdown» → «Копировать»** или **«Скачать .md»**.
6. Выбери **APPA 62**, повтори генерацию и сохранение.

Сохраняй результат **до переключения на другой товар**. Автоматической базы карточек нет.

| Кнопка | Назначение |
|---|---|
| Выбор товара | Только загрузить входные данные |
| Проверить данные | Факты/пропуски, без LLM |
| Готовый пример | Сохраненный реальный ответ, без нового запроса |
| Сформировать карточку | Новая генерация через API |
| Пример с пропусками | Заменить JSON учебным неполным входом для проверки ошибок |

**`needs_review` / «есть уточнения» — не сбой:** неизвестные характеристики отмечены «данных нет». Не заполняй их по догадке.

## 👀 Проверка вообще без ключа

После установки зависимостей запусти:

```powershell
.\.venv\Scripts\python.exe run.py --host 127.0.0.1 --mode demo
```

Тот же адрес: http://127.0.0.1:8010/. Доступны реальные сохраненные примеры, проверка JSON и экспорт. Новая генерация отключена намеренно.

## 🧪 Автотесты

В отдельном PowerShell **из той же папки** либо после остановки сервера:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты изолированы от ключа и сети, не вызывают LLM. Проверено 130 успешных тестов; итог — `reports/TEST_REPORT.md`. Одно предупреждение Starlette/TestClient не является падением тестов.

## ⚠️ Короткая диагностика

| Ситуация | Действие |
|---|---|
| Генерация отключена / `api_key_missing` | Повтори `scripts.configure`, перезапусти сервер |
| `provider_auth_error` | Проверь полный действующий ключ и разрешения аккаунта |
| `provider_rate_limit` | Подожди: ограничение бесплатного провайдера; установка модели не нужна |
| `invalid_model_output` | Непроверенный текст отклонен; можно повторить запрос |
| `insufficient_data` | Добавь подтвержденные параметры/назначение |
| Открывается другое приложение | Используй именно `127.0.0.1:8010`, не старый `localhost:8000` |
| Порт занят | Останови прежний сервер или добавь `--port 8011`, открой соответствующий адрес |
| После изменения `.env` ничего не поменялось | Ctrl+C и запусти сервер заново |

Если установщик сообщил о другой непустой переменной `LLM_API_KEY` в Windows, она имеет приоритет. Чтобы использовать файл, выполни в текущем PowerShell `Remove-Item Env:LLM_API_KEY -ErrorAction SilentlyContinue` и перезапусти проверку/сервер. Пустая переменная обрабатывается автоматически.

**Остановить:** Ctrl+C. **Повторный запуск:** только команда `run.py`; переустановка зависимостей и повторный ввод ключа не нужны.

Не публикуй `.env` и не присылай его на скриншотах. `/health` показывает настройки/наличие ключа, но не сам секрет.
