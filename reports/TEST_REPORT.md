## Что важно понимать

- Демо показывает сохраненный результат и не имитирует новое обращение к LLM.
- `needs_review` отражает неизвестные/неоднозначные характеристики, не сетевую ошибку.
- При оборванном параметре заголовка сервис может взять короткое исходное имя с предупреждением, не угадывая единицу. Описание остается ответом модели.
- Числовые/структурные проверки не заменяют технического редактора и независимую сверку паспортов.
- API бесплатного сервиса может ограничивать запросы. В преднастроенном :free-профиле запрещены endpoints с ненулевой ценой prompt/completion; автоматической оплаты/платного fallback нет.
