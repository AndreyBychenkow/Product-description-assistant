Документация API

Простой интерфейс для работы с фактами и генерации карточек. Все стили, скрипты и шрифт включены в приложение — без внешнего CDN.

Приложение отдельно. Модель отдельно.

В APP_MODE=demo работают проверка входа, экспорт и сохраненные реальные примеры. Новые ответы не генерируются. Приложение не устанавливает и не скачивает модели.

Для новой генерации задайте в .env режим llm, адрес LLM_BASE_URL, ID LLM_MODEL и LLM_API_KEY, если он требуется. Основной профиль — openai_compatible. После изменения настроек перезапустите сервер.

Сохраненный ответ имеет origin=saved_example, новая обработка — origin=live. Факт вызова модели уточняется по metadata.mode и дате генерации. Ключи в JSON товара не вводятся.

Методы

МетодПутьНазначение
GET/healthНастройки, режим и счетчик. Полный API-ключ не возвращается; наличие настроек не является отдельной проверкой доступности модели.
POST/api/inspectПроверка JSON, фактов и пропусков. Без обращения к LLM.
POST/api/generateНовая генерация: result, markdown и происхождение ответа. Время зависит от выбранного API.
GET/api/examplesДва исходных товарных примера.
GET/api/examples/{slug}Входной JSON: testo-830-t1 или appa-62.
GET/api/examples/{slug}/resultСохраненный реальный результат. Новый запрос к модели не делается.

Пример запроса

curl -X POST http://127.0.0.1:8010/api/generate \
  -H "Content-Type: application/json" \
  --data-binary @examples/inputs/testo-830-t1.json

Основные поля: name, manufacturer, плоский словарь specs и description. Неизвестные значения — null. Необязательно: expected_specs, source_urls, source_warnings, target_audience, use_cases. Ссылки источников сервером не скачиваются.

Спецификация OpenAPI: открыть JSON →.

Ошибки без неприятных сюрпризов

503 / demo_mode — выбран просмотр без новой генерации. 422 — некорректный JSON/структура, 413 — больше 128 КиБ. 502/503/504 — ошибка доступа, квоты, сети, таймаута или результата модели.

Ошибка возвращается в error с безопасными code, message и подробностями проверки. Секретные данные провайдера не печатаются. Подмены ошибки готовым примером нет.

Бедный вход → status=insufficient_data, metadata.attempts=0. needs_review означает, что черновик содержит поля для уточнения, а не ошибку соединения. Для короткой реальной проверки API: python -m scripts.check_connection.
